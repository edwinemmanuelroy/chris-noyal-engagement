# Chris & Noyal: Engagement Invitation

A single-page, mobile-first engagement invitation in ivory and sage green.

**Engagement:** Saturday, 26 December 2026, 4:00 PM, St. George Forane Church, Vazhakulam
**Reception:** St. George Parish Hall, following the ceremony

## What's inside

- Line-drawn laurel wreath loader (tap to skip)
- Hero with handwritten-style name reveal
- Families, programme with directions, Save the date (Google Calendar), live countdown
- Large, fluid type for easy reading on phones and desktops
- Respects "reduce motion" settings

## Run it

It's one static file with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
